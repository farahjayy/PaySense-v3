# P0 dependency & memory spike

Resolves `ASSUMED:` items 1 and 2 (PRD §8 Q1–Q2; D-23, D-15). Generated by hand from a throwaway uv project outside the repo; the measuring script was a ~40-line `psutil` RSS probe (not committed — numbers below are the record).

- **Host:** Windows 11, uv 0.12.23, CPython **3.12.15** (uv-managed). Date 2026-10-08.
- **Result 1 (Python version):** every package installed and imported on **3.12.15**, including `prophet` (bundled cmdstan, fitted one model), CPU `torch`, `statsforecast`, `xgboost`, `lightgbm`, `shap`, `onnxruntime`. Python 3.14 was not attempted: the 3.12 pin worked first time, and D-23 only needed one version that works.
- **Install note:** `torch` must come from the PyTorch CPU index (`https://download.pytorch.org/whl/cpu`) with `--index-strategy unsafe-best-match`; without that, the CPU index shadows `numpy` and resolution fails. `requires-python` must be bounded (`>=3.12,<3.13`) or uv tries to also solve for 3.14.

## Conclusions

1. **D-23 decided:** Python **3.12** (uv pin `3.12`).
2. **D-15 escape hatch step 1 is required:** a process with PyTorch loaded (607 MB) does not fit Render's 512 MB. The backend runtime must **not import torch**. The global LSTM is trained offline in `ml/` (torch in a separate dependency group) and **served via ONNX Runtime**, which is already in the served set. Prophet, if it is the Engine 1 winner, fits (~+15 MB in-process).
3. **The served set alone (no torch) is borderline, not comfortable:** 300–470 MB depending on what is resident. Real headroom depends on the loaded artefacts and Monte Carlo arrays, which don't exist yet. Re-measure with the real stack at the end of P4 and P6, and again on Render in P8. If it exceeds ~450 MB then, Cloud Run at 1 GiB (D-15 step 2) is the fallback. Lazy-importing `shap` only on the risk path is a cheap further saving to try first.
4. Memory was measured on Windows; Linux RSS on Render will differ somewhat (typically lower for shared libs). Treat these as upper-bound indicators, not Render guarantees.
