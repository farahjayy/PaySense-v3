# PaySense v3 — Build Status

> **Read this first to know where we are.** Updated at the end of every build session. Phases and scope come from `refdocs/paysense-v3-PRD.md` §6. Don't reorder phases without updating this file and saying why (CLAUDE.md "keep docs current").

**Build philosophy:** dependency order, no dates. Each phase ends green — tested and actually run — before the next one starts. Port what v1 proved, rebuild what v1 got wrong, and never ship a number that doesn't trace to a model, a simulation or the user's data.

**Fork (2026-10-18):** this repo is PaySense v3, the FinTechaton 2026 Shenzhen variant forked from v2 at `cdd43cf`; docs relabelled, competition scope is `refdocs/fintechathon-2026/work-packages.md` (WP0–WP19) with ADRs D-47 to D-52.

**Right now (2026-10-18, competitive-edge round):** the headline feature, the **Second-Opinion Check** (D-57), is built end to end: on every risk check the simulated chance of running short without and with the purchase and what it adds, every unpaid instalment across providers stacked by month, the exposure against the RM1,500 line, and a timing search ("Find a better time" / `find_safer_timing`) — backend, assistant, risk screen, saved report and assistant cards; no migration needed.
